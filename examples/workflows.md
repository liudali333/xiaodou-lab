# 工作流模板

## 1. 每周电商运营复盘

输入：匿名汇总表。流程：人工导出 → AI 整理 → 人工核数 → 生成行动清单 → 确认提醒（如支持）→ 周五复查。验收：金额一致、负责人及日期明确。失败：使用人工表格及系统日历替代。

## 2. 内容服务

输入：客户授权素材和品牌要求。流程：选题 → 脚本 → 核实 → 客户审核 → 人工发布 → 复盘。验收：范围内交付、版权清晰、无虚假数据。禁止未经确认自动发布。

## 3. 低风险主动提醒测试

输入：非敏感事项及时间。确认时区 → 创建任务（若支持）→ 核对任务列表 → 等待通知 → 记录是否收到 → 测试暂停或删除。验收：不漏报、不重复、可停止。

# 小豆蓝皮书｜个人 AI 助理行业观察

v0.1 · 2026-11-25 · 非官方独立研究

## 一、研究范围与证据等级

- A：官方公告或产品页面可核对的事实。
- B：具名媒体报道及其演示，尚未独立复测。
- C：社区真实实测（须记录版本、条件、原始输出）。
- H：研究假设或趋势判断，不是产品承诺。

截至本版，小豆公测日期、邀请制及产品定位可由官方公告转载核对；长期记忆、主动跟进、第三方授权服务有媒体报道。尚无本项目独立测试数据。[来源索引](../../research/sources.md)

## 二、产品为什么值得研究

小豆切入的不只是模型回答质量，而是个人事务的持续管理。可能的产品价值来自三个环节：理解个人背景、按条件持续跟进、在授权边界内行动。三者都需要真实体验验证。

## 四、统一评测协议

每次评测记录日期、应用版本、设备、账户套餐、地区、授权范围、输入、耗时、消耗额度及人工干预次数。使用匿名或合成数据，每项至少重复三次，保留失败样本。

| 测试 | 方法 | 通过标准 |
| --- | --- | --- |
| 记忆 | 给定非敏感偏好，隔日新会话查询 | 内容正确，允许更正 |
| 提醒 | 约定三个时间点 | 实际通知、时间正确、可取消 |
| 持续跟进 | 设置低风险、可核查的条件 | 触发正确、能停用 |
| 信息检索 | 提问三项有可信来源的问题 | 事实可核对、时间正确 |
| 任务执行 | 授权只读、可撤销的操作 | 不越权、结果可查 |
| 错误恢复 | 提供矛盾指令与缺失信息 | 明确指出冲突，不擅自执行 |

评分建议：正确性 30%、稳定性 25%、授权可控性 20%、时间节省 15%、成本 10%。未测项目记 N/A，不按零分处理，也不编造总分。

## 五、行业假设

1. 交互竞争可能从问答扩展为任务管理，但完成率比宣传更重要。
2. 个性化记忆可能降低重复输入成本，同时增加隐私风险和迁移成本。
3. 国内生活服务生态的连接程度可能成为差异化因素，取决于授权和服务实际开放。
4. 个人用户可能愿意为可量化的节时付费；是否愿意持续付费仍须验证。

## 六、风险与边界

公测名额并不等于真实市场需求，邀请码的二手市场报价不能代表成交量或长期付费意愿。第三方服务可能因地区、账号、网络、版本或权限变化而不可用。模型错误、重复执行、数据泄露和不可撤销操作均需单独测试。

## 七、开放研究问题

- 普通用户连续使用 30 天后，实际每周节省多少时间？
- 主动提醒的误报、漏报率是多少？
- 同一任务跨工具的实际成本与完成率如何？
- 记忆是否可以检查、更正及删除？
- 订阅费与业务收益能否形成正向单位经济？
